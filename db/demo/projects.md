# Alex Example – Selected projects

## Route planner for parcel lockers (Harbour Parcel, 2023)

Led a three-person team that built a service suggesting the nearest parcel lockers with free space.
Ruby on Rails API with PostgreSQL and PostGIS for distance queries; locker availability cached in Redis.
Load-tested it to 300 requests per second before launch and mentored a junior developer through
their first production feature.

## Event-driven order updates (side project, 2024)

Experimented with publishing order events from a Rails app to RabbitMQ and consuming them in a small
Sinatra service. Learned about idempotent consumers and dead-letter queues.

## Teaching

Ran a monthly internal "Rails clinic" where colleagues brought code to review together.
